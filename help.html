A small guide for getting MELO running, connecting Spotify, using your account, and troubleshooting the Windows desktop.

01 / GETTING STARTED

START HERE.

Install MELO

  1. Download the latest Windows installer from GET MELO.
  2. Run MELO.exe and complete the installation.
  3. Launch MELO from the Desktop or Start Menu.

Play local music

  1. Open the music/library area in MELO.
  2. Add or choose your local music files.
  3. Use the queue and playback controls to listen.
Spotify is optional. Local music can be used without adding a Spotify Client ID.
02 / SPOTIFY

CONNECT SPOTIFY.

Create a Spotify Developer app

  1. Open the Spotify Developer Dashboard.
  2. Create an application for your own Spotify account.
  3. Copy the application's Client ID.

Add your Client ID

  1. Open MELO.
  2. Go to Tools & Settings → Spotify.
  3. Select Add Spotify Account.
  4. Enter your own Client ID.
  5. Complete Spotify authorization.

Multiple accounts

MELO can keep multiple Spotify account/client profiles locally. Select the account you want to use from Spotify settings.

Authorization trouble

Check that your Spotify Developer app uses the redirect URI shown by MELO, that the Client ID is correct, and that the Spotify authorization window completed successfully.

03 / ACCOUNT

YOUR MELO ID.

Create an account

Use the MELO account sign-in flow from the website or supported MELO surfaces. Your account connects your profile and listening activity.

Listening statistics

When signed in, supported MELO players can send listening events to your account so your listening statistics can be displayed.

Player Card

Your Player Card presents your MELO identity and listening information. Visibility controls are available where supported by your profile settings.

Profile

Use your profile settings to manage your MELO handle, bio, pronouns, country and profile image where available.

04 / DESKTOP

WINDOWS DESKTOP.

Installer

The installer is the normal Windows installation. It creates the MELO application and shortcuts.

Portable build

The portable ZIP can be extracted to a folder and launched without using the normal installer.

Updates

MELO Desktop can check the MELO update service when update checking is enabled in its configuration.

Configuration

User configuration and Spotify account information are kept separately from the public release files. Do not share private credentials or tokens.

Still stuck?

Check the release archive for the version you installed, then report the exact version and what happened. Avoid sharing passwords, Spotify secrets, access tokens or other private credentials.
